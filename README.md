# 採用アセスメント

新卒・中途それぞれの選考向けに、性格診断(ビッグファイブ)・適性診断(論理・数的・言語、時間制限つき)・カルチャーフィット診断を実施し、採用担当者が結果を一覧・CSV出力できるツールです。

## 動かし方

このアプリは単体のHTMLファイル(`index.html`)ですが、候補者リンクの発行・回答の保存・結果一覧などはすべて [Claude Artifact](https://claude.ai) が提供する共有データベース機能(`window.claude.use("db")` など)に依存しています。そのため **GitHub Pages など外部に単体で設置しても、保存・管理機能は動作しません**。実際に動く状態で使うには、Claude 上で公開された以下のアーティファクトを利用してください。

- 公開アーティファクト: https://claude.ai/artifact/ANaqtrNSJvsrY5WV9c5rKd

このリポジトリはソースコードの保管・共有・差分管理のためのものです。

## 制約・注意事項

- 候補者も Claude へのサインインが必要です。また、リンクを送る前にアーティファクトの共有設定を「リンクを知っている全員が編集可能」にする必要があります。
- アクセス制御は共有権限(Viewer/Contributor/Editor)単位のため、編集可能リンクを持つ人はデータ層上で他の候補者の結果も読み取り可能です。候補者ごとの厳密な分離はできないため、社内トライアル・小規模な検証用途を想定しています。
- 性格診断・カルチャーフィット診断は自作の簡易的な指標であり、心理測定学的な妥当性・信頼性が検証されたものではありません。適性診断・性格診断の結果のみで合否を判断せず、面接など他の選考要素と組み合わせて補助的に活用してください。
- 性別・年齢・出身等、職務と無関係な属性による不公正な判断を避けてください(参考: 厚生労働省「公正な採用選考の基本」)。
- 候補者の回答は個人情報です。利用目的を明示し、安全に管理し、不要になった際は削除してください。

## 本格的な実運用を検討する場合

候補者データを厳密に分離し、自社のデータベース上で管理したい場合は、Node.js などの実行環境を用意した上で、Next.js + データベースによる専用のWebアプリケーションとして作り直すことを推奨します。
